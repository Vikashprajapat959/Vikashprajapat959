## 🧠 Engineering Workflow

I follow a structured approach when building software projects.

```mermaid
flowchart TD
    A([Problem / Idea]) --> B[Understand Requirements]
    B --> C[Plan Architecture]
    C --> D[Frontend Development]
    C --> E[Backend Development]
    D --> F[Integration]
    E --> F
    F --> G[Testing & Debugging]
    G --> H[Documentation]
    H --> I[Deployment & Improvement]
```
